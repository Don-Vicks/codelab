What is an Array?

Storing a collection of values

Definition

An array is a data structure used to store a fixed-size sorted collection of elements of the same type. It allows storing multiple variables under a single name.

Key Features:

  • Fixed Size: Configured when instantiated.
  • Indexed: Starting from 0 to `length - 1`.
  • Same Type: E.g., An array of `int`s can only hold integers.

Array Declaration & Access

Creating and returning array items

Declaration and Initialization:

// 1. Declaration only
int[] scores;
scores = new int[5]; // Array holds 5 integers

// 2. Declaration with Initialization
String[] names = {"Ali", "Musa", "Binta"};

Accessing Elements:

System.out.println(names[0]); // Prints "Ali"
names[1] = "Sani"; // Changes "Musa" to "Sani"

Processing Arrays

Iterating with Loops

Using the length property:

Every array has a length property indicating its size.

Example: Printing all elements

int[] numbers = {10, 20, 30, 40, 50};
for (int i = 0; i < numbers.length; i++) {
    System.out.println("Element at index " + i + ": " + numbers[i]);
}

The For-Each Loop

Enhanced Loop for Arrays

Definition

Introduced in Java 5, the enhanced for loop provides a simpler way to iterate through an array or collection, avoiding index manipulation.

Example:

String[] fruits = {"Apple", "Mango", "Banana"};
for (String fruit : fruits) {
    System.out.println(fruit);
}

Introduction to Methods

Modular Code Design

What is a Method?

A method is a block of code which only runs when it is called. You can pass data, known as parameters, into a method, and they can return a result.

They are used to perform certain actions, and they are also known as functions.

Why use Methods?

  • Code Reusability: Reuse logic without copy-pasting code.
  • Readability: Break down complex problems into smaller understandable components.
Slide 7 of 12 • Method Intro

Declaring a Method

Syntax & Structure

Structure:

public static returnType methodName(type arg1, type arg2) {
    // method body / logic inside
    return value; // if return type is not void
}

Example: Void Method

public static void printGreeting(String name) {
    System.out.println("Hello, " + name + "!");
}
Slide 8 of 12 • Method Syntax

Calling a Method

Invoking Logic

Usage inside main

public class Main {
    public static void printGreeting(String name) {
        System.out.println("Hello, " + name + "!");
    }

    public static void main(String[] args) {
        // Call the method
        printGreeting("Donvicks");
    }
}
Slide 9 of 12 • Method Invocation

Methods with Return Values

Capturing Output

Returning Data

If you want a method to return a specific data type instead of void, specify the type and use the return keyword.

public static int addNumbers(int a, int b) {
    return a + b;
}

public static void main(String[] args) {
    int result = addNumbers(5, 10);
    System.out.println("Result: " + result); // Prints 15
}
