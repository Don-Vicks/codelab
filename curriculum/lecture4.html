Why Getters & Setters?

Controlled Access

Direct access to fields allows any part of the program to change data to anything. Getters and Setters provide a "gatekeeper" mechanism.

private String name;

// Getter
public String getName() {
    return name;
}

// Setter
public void setName(String newName) {
    this.name = newName;
}

Getter vs Setter

Quick Comparison

Getter: Used to *retrieve* data. Always has a return type. No parameters.

Setter: Used to *update* data. Usually void. Takes at least one parameter.

Validation in Setters

Setters allow you to check if data is valid before saving it.

public void setAge(int age) {
    if (age > 0) {
        this.age = age;
    }
}

Summary

Encapsulation Essentials

  • Encapsulation keeps data safe.
  • Getters provide read-only access.
  • Setters provide write access with control.
  • Fields should almost always be private.
