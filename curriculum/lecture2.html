What are Control Structures?

Manual Reference: Module 4

Definition

Control structures determine the order in which statements in a program are executed. By default, execution is sequential (top to bottom).

Three Types of Flow:

  1. Sequential: Top to bottom execution (default).
  2. Selection (Decision): Choosing which path to take based on a condition (if-else, switch).
  3. Iteration (Looping): Repeating a block of code multiple times (for, while, do-while).

The if Statement

Making Simple Decisions

Basic Syntax:

Executes a block of code only if the specified condition is true.

if (condition) {
    // block of code to be executed if the condition is true
}

Example:

int age = 20;
if (age >= 18) {
    System.out.println("You are eligible to vote.");
}
Slide 3 of 15 • Basic Conditional Logic

The if-else Statement

Handling the Alternative

Syntax:

Provides an alternative block of code to execute when the condition is false.

if (condition) {
    // executed if true
} else {
    // executed if false
}

Example:

int score = 45;
if (score >= 50) {
    System.out.println("Pass");
} else {
    System.out.println("Fail");
}

The if-else-if Ladder

Multiple Conditions

Syntax:

Tests multiple conditions in sequence until one is true.

if (condition1) {
    // block 1
} else if (condition2) {
    // block 2
} else {
    // default block
}

The switch Statement

Alternative to multiple if-else

Syntax & Usage:

Used to select one of many code blocks to be executed based on the value of a variable.

int day = 3;
switch (day) {
    case 1:
        System.out.println("Monday");
        break;
    case 2:
        System.out.println("Tuesday");
        break;
    default:
        System.out.println("Other Day");
}

Important: The break keyword prevents "fall-through" to the next case.

Introduction to Loops

Iterating in Java

Why use Loops?

Loops allow us to execute a block of code multiple times. This saves time, reduces errors, and makes code more readable.

Types of Loops in Java:

  • for loop: Used when the number of iterations is known.
  • while loop: Used when the iterations persist as long as a condition is true.
  • do-while loop: Similar to while, but guarantees at least one execution.
Slide 8 of 15 • Loop Concepts

The for Loop

Iterate a known number of times

Syntax:

for (initialization; condition; increment/decrement) {
    // code block to be executed
}

Example: Print 1 to 5

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
Slide 9 of 15 • For Loops

The while Loop

Condition-based Iteration

Syntax:

The loop continues to run while the condition remains true.

while (condition) {
    // code block to be executed
}

Example:

int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++; // Don't forget to increment to avoid infinite loops!
}
Slide 10 of 15 • While Loops

The do-while Loop

Execute at least once

Syntax:

Executes the block first, then checks the condition to see if it should repeat.

do {
    // code block to be executed
} while (condition);

Example:

int i = 1;
do {
    System.out.println(i);
    i++;
} while (i <= 5);
