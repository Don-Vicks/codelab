What is Java?

Understanding the programming language

Java Characteristics:

  • High-level, object-oriented programming language
  • Platform-independent: "Write Once, Run Anywhere" (WORA)
  • Strongly typed: Every variable must have a declared type
  • Automatic memory management (Garbage Collection)

Where Java is Used:

Application Examples
Desktop Applications IDEs, Media Players
Web Applications Enterprise systems, E-commerce
Mobile Applications Android apps
Embedded Systems Smart cards, IoT devices

Type Casting

Manual Reference: Page 4

Converting one data type to another

"Type casting means converting one data type into another, for example, turning an int into a double."

- Course Manual, Page 4

1. Widening Casting (Automatic):

Converting a smaller type to a larger type

byte → short → char → int → long → float → double

int myInt = 9;
double myDouble = myInt; // Automatic casting: int to double

2. Narrowing Casting (Manual):

Converting a larger type to a smaller type (requires explicit cast)

double → float → long → int → char → short → byte

double myDouble = 9.78d;
int myInt = (int) myDouble; // Manual casting: double to int

Comments in Java

Manual Reference: Page 4

What are Comments?

"A comment is a piece of text included in the code to help humans understand the logic, purpose, or behavior of the program. The compiler ignores comments."

- Course Manual, Page 4

1. Single-Line Comment (//):

int age = 20; // this variable stores the student's age

2. Multi-Line Comment (/*...*/):

/* This program calculates the area of a circle. The formula is: area = π * r * r */
double area = 3.14 * radius * radius;

Operator Precedence

Manual Reference: Page 6

Order of Evaluation (Highest to Lowest):

  1. () - Parentheses
  2. * / % - Multiplication, Division, Modulus
  3. + - - Addition, Subtraction
  4. > < >= <= - Comparison
  5. == != - Equality
  6. && - Logical AND
  7. || - Logical OR

Examples from Manual (Page 6-7):

// Manual Page 7 Examples
int result1 = 10 - 2 + 5; // (10-2)+5 = 13
int result2 = 10 - (2 + 5); // 10-7 = 3

Question from Manual (Page 13):

"How does precedence affect a + b * c?"

Answer: Multiplication (b * c) happens first, then addition with a.

Common Errors & Debugging

Based on Manual Content

Compilation Errors:

  • Missing semicolon (;)
  • Mismatched brackets { }
  • Undefined variables
  • File name ≠ class name

Runtime Errors (Lab Task 2C Q1, Page 12):

"What happens if you enter a string where an integer is expected?"

Answer: InputMismatchException - Program crashes unless handled.

Logical Errors:

  • Wrong operator precedence
  • Incorrect data type usage
  • Off-by-one errors in loops (covered later)

Best Practices

From Manual Examples

Coding Standards:

  1. Meaningful variable names: studentAge not a
  2. Consistent indentation: Use 4 spaces
  3. Comment complex logic (as shown in manual)
  4. Test with different inputs

Naming Conventions:

  • Classes: PascalCase (FirstProgram)
  • Variables/Methods: camelCase (studentAge)
  • Constants: UPPER_CASE (MAX_SIZE)

From Manual Page 12 (Lab Task 2C Q2):

"Explain the importance of variable type selection."

Answer: Choosing the right type ensures memory efficiency, prevents errors, and makes code clearer.
